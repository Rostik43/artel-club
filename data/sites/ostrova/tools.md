# Острова — опись сайта (острова.рф)

Дата сбора: 2026-07-10. Источник: главная https://острова.рф/ и проект «Новый город» https://острова.рф/projects/novyy-gorod/.

| Признак | Да/Нет | Примечание |
|---|---|---|
| Конфигуратор / подбор по параметрам / выбор на генплане | Частично | Фильтр квартир по числу комнат (студии, 1–4-комн.) в меню «Недвижимость»; на странице проекта — блок «Выбрать квартиру». Визуального выбора на генплане/интерактивной схеме дома не обнаружено. |
| 3D-туры / панорамы / визуализации двора/МОП | Частично | На странице проекта есть галерея «Видео и фото» с разделами «Видео» и «Благоустройство» (видео/фото двора). Интерактивных 3D-туров или панорам не обнаружено. |
| Ипотечный калькулятор / «платёж от … ₽/мес» на 1-м экране | Да | На главной под каждой карточкой ЖК указан платёж («от 19 261 руб/мес», «от 28 620 руб/мес», «от 24 813 руб/мес»), хоть и не в самом первом hero-блоке. На странице проекта — полноценный ипотечный калькулятор (сумма кредита, ежемесячный платёж, ставки по программам). |
| Рассрочка / трейд-ин / субсидированные программы | Да | Отдельные разделы «Рассрочка», «Обмен жилья» (трейд-ин — обмен старой квартиры на новую с оценкой), «Материнский капитал», семейная/IT-ипотека. |
| Онлайн-бронирование / личный кабинет покупателя | Нет | На собранных страницах не обнаружено; есть только форма записи на экскурсию и офисы продаж. |
| Камеры стройки / ход строительства / дневник | Частично | Отдельных веб-камер не обнаружено, но есть регулярные новости о ходе строительства («Разрешение на ввод в эксплуатацию…», «Старт передачи ключей…», «Фокус-группа по эксплуатации двора на стилобате»). |
| Архитекторы / архбюро ПО ИМЕНИ | Нет | Упоминается только «мастер-планирование» и позиционирование «девелопер многофункциональных территорий»; ни архбюро, ни архитектор по имени не названы. |
| Слоган / главный заголовок 1-го экрана | — | Первый экран — слайдер без единого слогана: «Город-парк / Старт продаж», «Обмен жилья / Новая квартира взамен старой», «Квартиры с террасами / Удобство городской жизни и комфорт загородного дома». Ключевая фраза о компании ниже на странице: «Девелопер многофункциональных территорий и партнёр по развитию города». Заголовок страницы проекта «Новый город»: «Город для разного тебя». |

**Вывод по посылу:** Острова продают мастер-планирование районов, инфраструктуру шаговой доступности и финансовые удобства (ипотека, рассрочка, обмен жилья) — упор на девелоперский, а не архитектурный подход. Имя архбюро или архитектора не выносится в посыл вообще ни на одной из снятых страниц — акцент сделан на компании как «партнёре по развитию города», а не на авторстве проекта.
