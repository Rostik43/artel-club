# Росреестр: помесячный ряд ДДУ по УР — ⚠️ не удалось собрать в этой сессии

- **Дата попытки:** 2026-07-08
- **Цель (бриф п.3):** помесячный ряд зарегистрированных ДДУ по региону 18 за 2024–2026.

## Что мешает

1. **rosreestr.gov.ru — ошибка сертификата в Chrome.** Сайт использует сертификат
   «Russian Trusted CA» (Минцифры), которого нет в хранилище Chrome → интерстициал
   «Ошибка нарушения конфиденциальности». Расширение Claude-in-Chrome **не может** прикрепиться
   к нативной странице-ошибке (ни клик, ни `thisisunsafe`).
2. **curl -k доходит (200)**, но раздел «Статистика и аналитика» — это JS-портал (Liferay):
   в статическом HTML нет ни ссылок на ДДУ, ни Excel-файлов (проверено grep'ом —
   `.xls/.xlsx/.pdf` не найдены, упоминаний «долев/ДДУ» нет). Данные подгружаются скриптами.
3. **fedstat.ru (ЕМИСС)** — где лежит росреестровский индикатор по ДДУ — отдаёт **403/Forbidden**
   и curl'у, и браузеру (WAF блокирует).

## Сохранённые артефакты (evidence)

- `rosreestr_statistika_index_20260708.html` — страница «Статистика и аналитика» (curl -k).
- `rosreestr_statisticheskaya_otchetnost_20260708.html` — «Статистическая отчётность» (curl -k).

## Как закрыть вручную

- Установить сертификаты Минцифры (на сайте есть баннер «Установите сертификаты Минцифры России»),
  затем в браузере: rosreestr.gov.ru → «Открытая служба» → «Статистика и аналитика» →
  форма по ДДУ/сделкам → скачать Excel по субъекту РФ (Удмуртия, код 18).
- Альтернатива: ЕМИСС (fedstat.ru) — индикатор «Число зарегистрированных договоров участия
  в долевом строительстве», разрез по субъектам, экспорт в Excel (нужен доступ в обход WAF).
- Косвенный прокси уже собран: помесячную динамику спроса частично отражает распроданность
  по домам (`data/eisgs/houses.csv`) и срез реализации (`data/domrf/`).
