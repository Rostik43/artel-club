# Level Group — опись сайта (level.ru)

Дата сбора: 2026-07-10. Источник: https://level.ru/ и проект https://level.ru/projects/baumanskaya#office.

| Признак | Да/Нет | Примечание |
|---|---|---|
| Конфигуратор / подбор по параметрам / выбор на генплане | Да | На главной — развёрнутый фильтр квартир (комнатность, площадь, отделка, стоимость/платёж, район/метро, проект, срок сдачи, редкие форматы, вид из окна). На странице проекта — «ИИ-помощник по выбору жилья» (подбор по свободному текстовому запросу: бюджет, район, метраж) и кликабельный генплан с корпусами A/B/C. |
| 3D-туры / панорамы / визуализации двора/МОП | Да | На проекте отдельный блок «Панорама 360° на город и достопримечательности», ссылка «Виртуальная прогулка» у генплана, отдельная «Галерея» с 27 фото. |
| Ипотечный калькулятор / «платёж от … ₽/мес» на 1-м экране | Нет | Первый экран — промо-баннер «-35% на квартиры» без суммы платежа. Полноценный ипотечный калькулятор с платежами в ₽/мес («от 59 430 руб./мес.», «от 128 539 руб./мес.») есть, но в разделе «Способы покупки» ниже по странице проекта, не на первом экране. |
| Рассрочка / трейд-ин / субсидированные программы | Да | В футере — «Рассрочка Новое», «Материнский капитал», «Трейд-ин», «Трейд-ин Level+»; на проекте — блок «Способы покупки» с ипотекой, Level+ и «другими способами». |
| Онлайн-бронирование / личный кабинет покупателя | Да | В хедере — «Кабинет клиента» и «Кабинет брокера» (вход); отдельная страница «Как купить онлайн», на проекте — блок «Квартиры можно купить онлайн!». |
| Камеры стройки / ход строительства / дневник | Да | На проекте — раздел «Ход строительства» с фильтрами «Фото / Текстовый отчет / Видео» и помесячными подборками (десятки фото по месяцам 2023–2025). |
| Архитекторы / архбюро ПО ИМЕНИ | Да | На странице проекта Левел Бауманская прямо указано: «Изысканная архитектура от бюро ARCH(E)TYPE» и «Приватный зелёный двор от студии GAFA»; в тексте описания также: «Внешний вид корпусов Левел Бауманская — заслуга бюро ARCH(E)TYPE». |
| Слоган / главный заголовок 1-го экрана | — | На главной — крупный промо-баннер «-35% на квартиры» (карусель); на странице проекта первый экран — карточка «Левел Бауманская» с фактами (метро, площадь, класс, срок) и тем же баннером «-35% на квартиры». |

**Вывод по посылу:** Level продаёт скидки/выгоду (-35%, «специальная цена») и удобство подбора (ИИ-помощник, детальные фильтры, онлайн-покупка) — на первом экране всегда акция, а не архитектурная идея. Но в глубине карточки конкретного проекта Level — единственный из трёх — прямо называет и архбюро («ARCH(E)TYPE»), и ландшафтную студию («GAFA») по имени: авторство архитектуры подано как конкретный, проверяемый факт, а не общий эпитет.
