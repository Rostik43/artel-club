# ГК «А101» — опись сайта (a101.ru)

Дата сбора: 2026-07-09 (главная), 2026-07-10 (проект). Источник: https://a101.ru/ и проект https://a101.ru/projects/dom-na-dzhalilya/ («Дом на Джалиля»).

| Признак | Да/Нет | Примечание |
|---|---|---|
| Конфигуратор / подбор по параметрам / выбор на генплане | Частично | На главной — квиз «Пройдите тест, чтобы подобрать» и фильтры каталога (комнатность, стоимость, срок сдачи, класс, метро). На странице проекта — выбор корпуса (д.1.1 / д.1.2) списком. Интерактивного клика по генплану квартала в собранном тексте не зафиксировано. |
| 3D-туры / панорамы / визуализации двора/МОП | Частично | Есть статичные рендеры двора, центрального лобби, паркинга и кладовых (разделы «Благоустройство», «Центральное лобби», «Паркинг и кладовые»), но явных «3D-тур» / «панорама» в навигации или тексте нет. |
| Ипотечный калькулятор / «платёж от … ₽/мес» на 1-м экране | Нет | На собранных страницах нет виджета калькулятора с суммой платежа/мес — только промо-баннеры ставок («Ипотека 11,9 % для всех», «Ипотека для всех! Со ставкой 11,6 %»). |
| Рассрочка / трейд-ин / субсидированные программы | Да | В меню «Способы покупки»: Ипотека, Рассрочка, Трейд-ин, Трейд-ин Авто, Материнский капитал, Переуступка, Страхование, Семейная ипотека, Военная ипотека, Паркинг в ипотеку. |
| Онлайн-бронирование / личный кабинет покупателя | Нет | В собранных текстах нет ни «личного кабинета», ни онлайн-бронирования — есть подписка на рассылку и «Получить консультацию». |
| Камеры стройки / ход строительства / дневник | Частично | На странице проекта есть блок «Ход строительства» с указанием даты корпуса и ссылкой «Смотреть 2 фото», но термин «онлайн-камеры» / прямая трансляция не встречается. |
| Архитекторы / архбюро ПО ИМЕНИ | Да (частично) | На странице «Дом на Джалиля» указано: «Концепция паркинга разработана архитектурным бюро MORS ARCHITECTS». Это единственное упоминание именованного бюро на собранных страницах — оно относится только к интерьеру паркинга, а не к фасадам/общей архитектуре проекта, которая описана обезличенно («современный дом бизнес-класса», «архитектурная… доминанта района»). |
| Слоган / главный заголовок 1-го экрана | — | Главная: «Мы строим города, в которых хочется жить» (подзаголовок: «Создаём пространства, сообщества, связи. Каждый проект — единая комфортная среда для жизни, работы и отдыха»). Текущий промо на первом экране: «Старт продаж! «Хольм» — городские резиденции в лесу рядом с метро». Проект «Дом на Джалиля»: «Дом на Джалиля: квартиры от 18,7 млн ₽» / «Новая страница вашей истории». |

**Вывод по посылу:** А101 продаёт не квартиру, а «город для жизни» — образование, спорт, культуру, бизнес-среду и устойчивое развитие как единую экосистему; коммуникация лайфстайл-ориентированная, с крупной типографикой, светлым дизайном и щедрой фотографией. Авторство архитектуры в посыл почти не выносится: единственное именование бюро (MORS ARCHITECTS) касается второстепенного элемента — паркинга, а не концепции дома или фасадов, то есть архитектура как таковая используется как атмосферный фон («современный дом бизнес-класса», «архитектурная доминанта района»), а не как именной актив бренда.
