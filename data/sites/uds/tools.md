# UDS — опись сайта (uds-developer.ru)

Дата сбора: 2026-07-10. Источник: https://uds-developer.ru/ и проект https://uds-developer.ru/projects/ocean-city-2-ocered

| Признак | Да/Нет | Примечание |
|---|---|---|
| Конфигуратор / подбор по параметрам / выбор на генплане | Да | На странице проекта OCEAN CITY есть развёрнутый блок «Выбрать по параметрам» (тип недвижимости, комнаты, цена, площадь, этаж, расположение, отделка, срок сдачи, особенности) и отдельный блок «Выбрать квартиру на плане» с генпланом, где подписаны обе башни («OCEAN CITY, башня МИЛЛЕНИУМ (33 этажа)», «...башня ЭРА (15 этажей)»). На главной — подборки «я люблю» (по видам отделки, планировкам, сценариям жизни). |
| 3D-туры / панорамы / визуализации двора/МОП | Частично | Явных интерактивных 3D-туров/панорам в собранном тексте не найдено, но есть подробные рендеры и описания МОП: лобби с «премиальными брендами», приватный двор «на высоте 8 метров», фитнес-пространство, панорамное остекление — упор на визуализацию образа жизни, а не на интерактивный тур. |
| Ипотечный калькулятор / «платёж от … ₽/мес» на 1-м экране | Нет | На главной есть блок «Ипотека — получите одобрение от 19 федеральных банков», но это описание услуги, не калькулятор с суммой платежа. На странице проекта тоже нет конкретного «платёж от ₽/мес» — есть только акции со ставками (4%, 13,69%, 11,9%). |
| Рассрочка / трейд-ин / субсидированные программы | Да | Развитый блок «Способы покупки»: Ипотека, Материнский капитал, Рассрочка, IT-ипотека, Трейд-ин, Опционный договор («альтернатива вкладу»), УСН-1% для инвестирующих в недвижимость Удмуртии. Плюс акции «Ипотека от 4%», «Рассрочка 0%», «Рассрочка на коммерцию». |
| Онлайн-бронирование / личный кабинет покупателя | Да | В шапке сайта — «Кабинет клиента» и «Кабинет риелтора». Также сервис «Цифровая сделка» с УКЭП — оформление документов на покупку без визита в МФЦ/Росреестр. |
| Камеры стройки / ход строительства / дневник | Да | На странице ЖК OCEAN CITY — подробный трекер «Ход строительства» с процентом готовности по месяцам (с мая 2025 по май 2026, от 12,5% до 52%). |
| Архитекторы / архбюро ПО ИМЕНИ | Да | На главной, в блоке «Преображаем города»: «Мы сотрудничаем с мировыми архитектурными бюро, такими как mla+, Benoy, cie.nl, Dyer». Это единственный застройщик из выборки, где архбюро названы по именам как часть ценностного предложения. |
| Слоган / главный заголовок 1-го экрана | — | Главная: первый экран — карточка конкретного проекта «ECO LIFE ВЕСНА, ДОМ 3» с параметрами (цена, готовность 90%, срок ключей, число квартир) поверх фонового фото сквера; общего слогана на первом экране нет. Ниже по странице — смысловой заголовок компании «UDS — девелопер, создающий будущее». Первый экран проекта OCEAN CITY: «OCEAN CITY, БАШНЯ МИЛЛЕНИУМ» с подзаголовком-цифрами (стоимость, готовность, число квартир). |

**Вывод по посылу:** UDS продаёт статус, масштаб и мировые стандарты — небоскрёб «выше всех», премиальный сервис отельного уровня («Чистый старт»), обширную линейку финансовых инструментов (от опционного договора до УСН-1%) и явно называет международные архбюро (mla+, Benoy, cie.nl, Dyer) как часть бренда «Преображаем города». Для бюро «АРТЕЛЬ» это единственный застройщик выборки, который прямо выносит имя архитектурного партнёра в посыл — сильный референс того, что рынок готов покупать историю «известное архбюро спроектировало этот дом».
