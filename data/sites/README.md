# Снапшоты сайтов застройщиков — 16 компаний

Сбор для бенчмарка посылов «УР vs федералы» (см. `docs/site-audit-brief.md`).
**Дата сбора: 2026-07-09 — 2026-07-10.** Сбор — с российского IP (178.208.77.90).

## Метод

- Основной инструмент — **Playwright + Chromium (headed), viewport 1440×900, UA обычного Chrome**,
  локаль ru-RU, `ignoreHTTPSErrors`, стелс-патчи (`navigator.webdriver` скрыт).
- Для каждого застройщика — папка `data/sites/<слаг>/`:
  - `home.txt` — видимый текст главной (innerText после прокрутки),
  - `home.png` — скриншот главной,
  - `project.txt` / `project.png` — то же для одного флагманского ЖК,
  - `tools.md` — опись фактов (8 признаков + вывод по посылу),
  - `links.json` — собранные ссылки главной (для выбора проекта).
- **Скриншоты сжаты**, чтобы уложиться в разумный размер репозитория: ресайз до ширины 1000 px,
  очень длинные страницы обрезаны сверху до 5200 px, палитра квантована до 256 цветов
  (текст/раскладка читаются; итог ~24 МБ вместо ~74 МБ).

### Известные ограничения
- **ПИК и Самолет** — за Qrator WAF: автоматический headless-браузер блокируется (HTTP 403).
  Текст снят через реальный браузер; полностраничные PNG для этих двух НЕ сохранены
  (в `tools.md` — наблюдения по живой странице). Остальные 14 сайтов сняты полностью.
- Скриншоты — уменьшены и квантованы (см. «Метод»): для дизайн-аудита читаемость сохранена,
  для пиксель-точного сравнения используйте живые сайты.

Только публичные страницы. Персональные данные и закрытые разделы не собирались.
