Полная проверка достоверности данных исследования перед докладом. Триггер — находка

первоисточников; (4) свежий срез ЕИСЖС через fetch() во вкладке Chrome (API за WAF Servicepipe).

## 1. Цифры доклада (ЕИСЖС, срез 08.07) — ВСЕ ПОДТВЕРЖДЕНЫ ✅

Пересчёт `analyze_houses.py` по `houses.csv` воспроизводит каждую цифру доклада:
118 домов / 22 111 квартир / ~1,09 млн м² / 31,1%; навес-2028 (9 796 кв = 44,3%, распродано 15,4%);
кирпич 47,3% vs монолит-кирпич 28,1% (×1,68); 18–24 эт. — 11 144 кв (50,4% рынка), 26,5%;
классы: комфорт 33,1% / типовой 17,5% / элитный 14,0%; цена 130–160 тыс — 37,2%, 160–200 — 23,4%;
Острова 3 дома / 989 кв / 37,3%; агломерация 95,3% квартир (Ижевск 72,7% + Завьялово 22,6%).

Нюансы формулировок:
- «Разброс ×20, от 4% до 80%» — это АСПЭК-Домстрой 4,2% → АССО-Строй 80,7% (×19,2).
  Формально в данных есть и Символ Девелопмент 2,8% (1 дом), т.е. фактический разброс до ×28 —
  заявление ×20 консервативно, не уязвимо.
- Распроданность известна у 98 из 118 домов; 31,1% — взвешенное по квартирам среднее по ним.

## 4. Сайты застройщиков (16 из 16 проверены)

Сводка: подавляющее большинство признаков и цитат подтверждены дословно. Найдено:

### Ошибки и правки (внесены в документы)

1. **Острова — главная находка (подтверждена находка пользователя).** На сайте моиострова.рф
   полный каталог `/flats/` с фильтрами; на каждой квартире кнопка «Забронировать» → форма
   (имя + телефон + время звонка) с карточкой квартиры. Это **онлайн-заявка на бронь**, а не
   «офлайновая модель („лично посетить офис")» из досье. Нюанс: полноценной онлайн-брони
   с оплатой и личного кабинета действительно нет — форма без оплаты. Также устарело:
   на сайте теперь «Скидка 13%» (до 31.08, при 100% оплате/рассрочке/части ипотек) и
   «Семейная ипотека 5,75%», платёж «от 28 387 ₽/мес» на карточке квартиры.
   Источник старой ошибки: досье писалось по СМИ-сниппетам, когда сайт был недоступен
   из облака; снапшот покрыл только 2 страницы.
2. **Level — цитата не существует.** «Level Group входит в ТОП-5 застройщиков с самым высоким
   рейтингом доверия» — на живом сайте (включая /news) не найдена. Реальные факты с сайта:
   кредитный рейтинг АКРА A-(RU) (подтверждён дек. 2025) и «топ-5 самых успешных девелоперов
   Старой Москвы по объёму выручки, топ-3 по числу ДДУ» (по данным «Метриум», блок «Правила Level №2»).
3. **Донстрой — склейка.** «За 30 лет построили целый город, в котором ни один дом не похож
   на другой» — это две разные карточки: «Мы работаем уже 30 лет! За это время построили целый
   город!» и «7,5 млн м² … В этом городе ни один дом не похож на другой». Как единую цитату
   использовать нельзя.
4. **Донстрой — Forbes.** На сайте: «По данным Forbes „Донстрой" занимает первое место в рейтинге
   уверенности застройщиков столицы в номинации „Жилье бизнес-класса"» — без «№1» и без года 2024.
5. **Железно — Face ID не подтверждён.** На странице ЖК «Миры» фраза отсутствует; фича описана
   как бесконтактный доступ («Технологии доступа работают бесконтактно…»). «Face ID» пришёл из СМИ.
6. **КОМОССТРОЙ — цитата первого экрана устарела.** «Скидка на все квартиры! 5%» → сейчас ротация:
   «5% на квартиры от Комосстрой! Предложение ограничено» (до 31.07), «Скидка … до 15%!» и др.
   Смысл («голая скидка») сохраняется, дословность — нет. Для доклада цитату датировать срезом
   или снять свежий скриншот накануне.
7. **Эталон — ЛК существует.** lk.etalongroup.ru — иконка в шапке без текста (поэтому текстовый
   сбор её не увидел) + «Онлайн-оплата» в футере. Вердикт «частично» был занижен.

## 6. Уязвимость формулировки «0 из 8 сайтов УР называют автора здания»

Строго говоря: УДС называет партнёрские бюро списком на главной (mla+, Benoy, cie.nl, Dyer),
Федерация называет МАДИ на лендинге отдельного ЖК, Талан — Cubica для двора, Острова — SPEECH.
Слово «системно» в докладе спасает, но со сцены безопаснее формула:
«Ни один сайт УР не привязывает имя архитектора к продаваемому дому так, как это делают федералы
на карточке проекта; ближе всех — Острова (SPEECH) и точечно Федерация (МАДИ на лендинге ЖК)».
