## Ключевые выводы исследования (короткая память)

- Рынок УР: 118 домов, 22 111 квартир, распроданность 31,1% (ЕИСЖС 08.07.2026), топ-10 РФ по здоровью.
- **Навес-2028**: 9 796 квартир (44% рынка) продано на 15,4% — главный риск и главный рынок для бюро.
- Монолит-кирпич (79% рынка) продаётся 28,1% против 47,3% у кирпича; формат 18–24 этажа — самый массовый и слабый.
- Потолок спроса ~160 тыс ₽/м² (лимит семейной ипотеки 6% ≈ бюджет 7,5 млн ₽); «типовой» класс проваливается (17,5%).
- Разброс распроданности между застройщиками ×20 — продукт решает; аутсайдеров вслух не называем.
- Стратегия бюро: продавать не «геймификацию», а «архитектуру как драйвер распроданности», вход через пилоты.

## Правила экономии токенов (договорённость с пользователем)

1. **Подсказывать про переезд в новую сессию.** Claude обязан сам предлагать пользователю
   начать свежую сессию, когда: (а) крупный блок работы закрыт и закоммичен; (б) разговор
   стал длинным и каждый ход дорого перечитывает историю (ориентир: контекст ужимался
   или диалог заметно старше 1–2 рабочих дней); (в) начинается новая большая тема.
   Перед переездом — убедиться, что всё запушено и CLAUDE.md обновлён: новая сессия
   должна войти в курс по этому файлу за минуту.
2. **Ярусные оркестры.** В Workflow субагенты-сборщики/поисковики — `model: 'haiku'` или
   `'sonnet'` (+ `effort: 'low'/'medium'`); Fable — только синтез, вердикты скептиков и
   тексты «под подпись» пользователя. Не дублировать чтение источников между агентами:
   одно извлечение → компактный JSON → остальные работают по нему.
3. **Тяжёлые запуски — сразу после сброса 5-часового окна**, не перед ним.
4. **Локальные сессии сбора данных — на Sonnet** (`/model sonnet`): они делят лимит
   подписки с облаком.
5. **Мониторинг:** `npx ccusage@latest blocks --live` (окно), `ccusage session` (прожорливые
   сессии).

## Технические ограничения среды

- Облачные сессии НЕ достучатся до наш.дом.рф / ЕРЗ / ЦБ / Росреестра: гео-блок российских
  госсайтов + сетевая политика. Сбор данных — только через локальную сессию с российским IP
  (см. `docs/local-data-collection-brief.md`) или ручную выгрузку пользователя.
- Слайды правим в `presentation/udmurtia-keynote.html`; артефакт-версия публикуется из сессии.
