# КОМОССТРОЙ — опись сайта (komosstroy.ru)

Дата сбора: 2026-07-10. Источник: https://komosstroy.ru/ и проект https://komosstroy.ru/projects/skandinaviya

| Признак | Да/Нет | Примечание |
|---|---|---|
| Конфигуратор / подбор по параметрам / выбор на генплане | Частично | На главной и на странице ЖК — фильтр «Выберите квартиру» (комнатность, цена, этаж), выдаёт число квартир («Смотреть 3317 квартир» / «Смотреть 263 квартиры»). Есть раздел «Генплан» на странице проекта, но это статичная картинка дома сверху, без кликабельных секций/квартир. |
| 3D-туры / панорамы / визуализации двора/МОП | Нет | На собранных страницах нет 3D-туров и панорам. Есть только фотографии/рендеры двора, парадной и интерьеров в блоке «Особенности проекта» (статичные изображения). |
| Ипотечный калькулятор / «платёж от … ₽/мес» на 1-м экране | Нет | Ни на главной, ни на странице ЖК «Скандинавия» не встречается калькулятор ипотеки или указание платежа в ₽/мес — только итоговая цена квартир. |
| Рассрочка / трейд-ин / субсидированные программы | Нет | На собранных страницах нет упоминаний рассрочки, трейд-ин или ипотечных программ. Из промо — только скидка «5%» на баннере и «Квартиры со скидкой» (акция на конкретные лоты, не финансовый продукт). |
| Онлайн-бронирование / личный кабинет покупателя | Нет | Не выявлено на снятых страницах — нет ссылок «Личный кабинет» или онлайн-брони. |
| Камеры стройки / ход строительства / дневник | Да | На странице ЖК «Скандинавия» есть раздел «Ход строительства» с фотографиями по месяцам/годам (2025–2026) и «Документация» (памятка новосёла). |
| Архитекторы / архбюро ПО ИМЕНИ | Нет | Есть фича «Скандинавская архитектура» в блоке «Особенности проекта», но конкретное архбюро или архитектор нигде не назван по имени. |
| Слоган / главный заголовок 1-го экрана | — | Единого фирменного слогана нет: первый экран — карусель промо-баннеров: «Скидка на все квартиры! 5%» и «Старт продаж новых домов! дома №8,9 в Солнечных кварталах Санвилл». Ниже — виджет «Поможем выбрать квартиру». На странице ЖК заголовок первого экрана — «Скандинавия» с подписью «Особая атмосфера, давшая основу проекту — "хюгге"». |

**Вывод по посылу:** КОМОССТРОЙ продаёт масштаб выбора и цену — на сайте выведено более 15 ЖК с фильтром по цене «от», акцент на скидках (5%, «квартиры со скидкой») и количестве доступных лотов (3317 квартир). Архитектура упоминается только как маркетинговый ярлык («скандинавская архитектура») без имени автора и без визуальных доказательств (3D, панорам). Для бюро «АРТЕЛЬ» сигнал слабый: авторство архитектуры не выносится в посыл вообще, застройщик работает в логике массового строительного каталога.
