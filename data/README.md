## Содержимое

### `eisgs/` — главное (п.1)
- `houses.csv` — 118 строящихся домов УР: дом → ЖК → застройщик → этажность → материал стен →
  срок сдачи → **% проданных (soldOutPerc)** → цена ₽/м² → генподрядчик → эскроу/проблемный.
- `raw/eisgs_api_dump.json` — сырой дамп (каталог + карточки), `raw/eisgs_fill_29.json` — дозагрузка.
- Собрано через API наш.дом.рф в авторизованной вкладке браузера (WAF блокирует прямой curl/urllib).
- **Ограничение источника:** «строительная готовность %» в публичном API не отдаётся (есть только
  плановая дата 100% готовности `objReady100PercDt`).

### `erz/` (п.2)
- `top-developers.csv` — топ-20 застройщиков УР по объёму текущего строительства на 01.07.2026
  (строится м², доля в регионе, перенос сроков, рейтинг ЕРЗ).
- `erz_top_udmurtia_20260701.html` — HTML-снимок страницы.

### `domrf/` (п.4)
- `udmurtia-realization-summary.md` — сводка: 118 домов, 22 111 квартир, распроданность 31,1 %.
- `udmurtia-realization-by-city.csv`, `udmurtia-realization-by-developer.csv` — разрезы.
- Рассчитано по дом-уровневым данным ЕИСЖС (тот же источник, что дашборд ДОМ.РФ), срез на 08.07.2026.

### `rosreestr/` (п.3)
- `README.md` — почему ДДУ-ряд не собран + как закрыть вручную; HTML-снимки страниц статистики.

### `status-checks.md` + `status-raw/` (п.5)
- Ключевая ставка ЦБ: 14,25 % (с 22.06.2026), полный ряд изменений с 2024. Ближайшее заседание 24.07.2026.
- Семейная ипотека (с 01.10.2026) и «вторичка» по 4 городам — источники SPA/WAF/cert недоступны
  программно; приведён критерий и объёмы стройки по городам из ЕИСЖС, флаги требуют ручного подтверждения.
