# Бриф для локальной сессии Claude Code: сбор рыночных данных по Удмуртии

Этот файл — задание для Claude Code, запущенного **локально на компьютере с российским IP**.
Облачная сессия не может достучаться до российских источников (гео-блок + сетевая политика),
поэтому сбор данных выполняется локально, результаты коммитятся в эту же ветку
(`claude/gamification-real-estate-6ekon3`), анализ продолжается в облаке.

Контекст: см. `docs/udmurtia-market-analysis.md` — готовый отчёт по рынку.
Раздел 9 отчёта («Пробелы в данных») — список того, что нужно закрыть. Здесь — рабочий план.

## Задание локальному Claude (скопируй как промпт)

> Прочитай docs/local-data-collection-brief.md и выполни его: собери данные по пунктам 1–5,
> положи результаты в data/, закоммить и запушь в ветку claude/gamification-real-estate-6ekon3.

## Что собрать (по приоритету)

### 1. ЕИСЖС: распроданность по каждому строящемуся дому УР — ГЛАВНОЕ
- Запусти `python3 scripts/market-data/fetch_eisgs.py` (регион 18 зашит по умолчанию).
- Скрипт постранично выкачает каталог наш.дом.рф и карточки ~118 домов в `data/eisgs/`.
- Если endpoint изменился (404/пустой ответ): открой https://наш.дом.рф каталог новостроек
  по Удмуртии в браузере/Playwright, найди XHR-запросы каталога в DevTools и поправь
  `CATALOG_PATH` в скрипте. Playwright с Chromium — рабочая альтернатива, если API закрыли.
- Цель: таблица дом → ЖК → застройщик → этажность → материал стен → срок сдачи →
  % проданных квартир → строительная готовность.

### 2. ЕРЗ: топ застройщиков УР и распроданность vs готовность
- https://erzrf.ru/top-zastroyshchikov/udmurtskaya-respublika — сохрани таблицу топ-10
  (объём в стройке м², доля региона) в `data/erz/top-developers.csv` + скриншот/HTML в `data/erz/`.
- Если страница рендерится JS — используй Playwright (Chromium установлен локально или
  `npx playwright install chromium`).

### 3. Росреестр: помесячный ряд ДДУ по УР
- https://rosreestr.gov.ru → «Открытая служба → Статистика и аналитика» → ДДУ по субъектам.
- Скачай Excel за 2024–2026, положи в `data/rosreestr/`, выпиши помесячный ряд по региону 18
  в `data/rosreestr/ddu-monthly.csv`.

### 4. ДОМ.РФ аналитика: свежий срез объёма стройки и распроданности региона
- https://наш.дом.рф → «Аналитика → Реализация квартир в строящихся домах», регион УР.
- Сохрани выгрузку/скриншот в `data/domrf/`. Нужен срез свежее Q3 2025.

### 5. Проверка статусов на текущую дату
- Ключевая ставка ЦБ: https://cbr.ru/hd_base/keyrate/ (и итог заседания 24.07.2026, если уже было).
- Параметры семейной ипотеки с 01.10.2026: спроси.дом.рф / publication.pravo.gov.ru.
- Список «семейная ипотека на вторичку» (статус Сарапула, Воткинска, Глазова, Можги):
  сервис на спроси.дом.рф, редакция от 01.07.2026.
- Запиши результат в `data/status-checks.md` с датой проверки.

## Правила
- Все файлы — в `data/` (создай каталог), сырые ответы сохраняй рядом с обработанными.
- В каждом CSV/MD указывай дату сбора и URL источника.
- Не парсь агрессивно: пауза ≥1 сек между запросами, «вежливый» User-Agent.
- Коммить в ветку `claude/gamification-real-estate-6ekon3`, пуш — `git push -u origin <ветка>`.
- После пуша облачная сессия обновит `docs/udmurtia-market-analysis.md` по собранным данным.
