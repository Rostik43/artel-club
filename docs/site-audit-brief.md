# Бриф для локальной сессии: сбор материалов с сайтов застройщиков

Задание для Claude Code, запущенного **локально с российским IP** (облако не достаёт до сайтов —
гео-блок/WAF). Результат коммитится в ветку `claude/gamification-real-estate-6ekon3`,
анализ выполняет облачная сессия.

## Промпт для запуска (скопируй локальному Claude)

> Прочитай docs/site-audit-brief.md и выполни его: собери материалы по всем 16 застройщикам
> в data/sites/, закоммить и запушь в ветку claude/gamification-real-estate-6ekon3.

## Что собрать по каждому (папка `data/sites/<слаг>/`)

Используй Playwright (Chromium установлен; если нет — `npx playwright install chromium`).
Пауза ≥2 сек между сайтами, обычный User-Agent, viewport 1440×900.

1. **`home.txt`** — весь видимый текст главной страницы (innerText после полной загрузки,
   прокрути страницу до конца, чтобы подгрузились ленивые блоки).
2. **`home.png`** — полностраничный скриншот главной (fullPage).
3. **`project.txt` + `project.png`** — то же для страницы ОДНОГО флагманского ЖК
   (первый/самый заметный проект с главной).
4. **`tools.md`** — короткая опись фактов, которые видно на сайте (формат — список Да/Нет + примечание):
   - конфигуратор квартиры / подбор по параметрам / выбор на генплане?
   - 3D-туры, панорамы, визуализации двора/МОП?
   - ипотечный калькулятор, «платёж от … ₽/мес» на первом экране?
   - рассрочка / трейд-ин / субсидированные программы?
   - онлайн-бронирование, личный кабинет покупателя?
   - камеры стройки / отчёты о ходе строительства / дневник стройки?
   - упоминание архитекторов/архбюро ПО ИМЕНИ? (критично для анализа!)
   - слоган/главный заголовок первого экрана (процитируй дословно)
5. Если сайт лежит/редиректит — зафиксируй это в `tools.md` и иди дальше.

## Правила

- **Коммить и пуши после каждых 3–4 застройщиков**, не копи всё до конца:
  `git add data/sites && git commit -m "Site snapshots: <кто собран>" && git push -u origin claude/gamification-real-estate-6ekon3`.
  Сессии прерываются — незапушенный прогресс теряется.
- **При повторном запуске** сначала проверь, какие папки в `data/sites/` уже заполнены,
  и собирай только недостающих.
- Всё складывай в `data/sites/<слаг>/`, в конце создай `data/sites/README.md`
  (дата сбора, что не удалось).
- PNG сжимай при необходимости (важно уложиться в разумный размер репо; если fullPage
  слишком тяжёлый — скриншот первых двух экранов).
- Не парси персональные данные и закрытые разделы, только публичные страницы.
- Коммит: `git add data/sites && git commit -m "Add developer site snapshots" && git push -u origin claude/gamification-real-estate-6ekon3`.

После пуша облачная сессия проведёт сравнительный анализ посылов (7 измерений)
и соберёт отчёт-бенчмарк «УР vs федералы».
