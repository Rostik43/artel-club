# ДОМ.РФ / ЕИСЖС — реализация квартир в строящихся домах, Удмуртская Республика

- **Дата сбора:** 2026-07-08
- **Источник:** наш.дом.рф, ЕИСЖС, каталог новостроек региона (place=18) + карточки домов
  (`/сервисы/api/kn/object`, `/сервисы/api/object/{objId}`).
- **Метод:** срез рассчитан по **дом-уровневым** данным ЕИСЖС (те же данные, что лежат в основе
  дашборда ДОМ.РФ «Реализация квартир в строящихся домах»). Это свежее, чем требуемый в брифе
  минимум «свежее Q3 2025»: срез на 08.07.2026. Распроданность = поле `soldOutPerc` карточки дома,
  взвешена по числу квартир.
- Полные исходники — `data/eisgs/` (houses.csv + raw JSON). Здесь — региональные агрегаты.

## Примечание о «строительной готовности»

Поле «строительная готовность %» в публичном API ЕИСЖС/наш.дом.рф **не отдаётся** (в карточке
есть плановая дата 100 % готовности `objReady100PercDt` и срок передачи, но не процент СМР).
Поэтому в `houses.csv` эта колонка не заполнена — это ограничение источника, а не пропуск сбора.
