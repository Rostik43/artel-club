# АСПЭК (АСПЭК-Домстрой) — опись сайта (dom.aspec.ru)

Дата сбора: 2026-07-10. Источник: главная https://dom.aspec.ru/ и каталог проектов https://dom.aspec.ru/projects. Сайт-SPA: контент подгружается JS, поэтому страница отдельного проекта (например, «Вега» или «Восход») не собралась отдельно — project.txt/png фактически дублируют общий каталог проектов, а не карточку конкретного ЖК.

| Признак | Да/Нет | Примечание |
|---|---|---|
| Конфигуратор / подбор по параметрам / выбор на генплане | Частично | В каталоге проектов есть переключатели «Все / Активные / Завершенные», фильтр «Город» и переключение вида (плитка/карта). В меню отдельно есть пункт «Подбор недвижимости» (страница не заснята). Выбора квартиры на генплане дома не обнаружено. |
| 3D-туры / панорамы / визуализации двора/МОП | Нет | Только статичные фото фасадов зданий на карточках проектов; текстом описаны «Удобные дворы», но визуализаций/панорам/3D-туров в собранном контенте нет. |
| Ипотечный калькулятор / «платёж от … ₽/мес» на 1-м экране | Частично | На 1-м экране — карусель проектов без цифр платежа. Платёж в ₽/мес встречается в блоке новостей: «Квартиры от 15 700 рублей в месяц» (ЖК Вега), но не как калькулятор и не на первом экране. В меню есть пункт «Ипотека» (страница не заснята). |
| Рассрочка / трейд-ин / субсидированные программы | Частично | В верхнем меню есть раздел «Способы покупки» — его содержимое не заснято в этом сборе, поэтому конкретные программы (рассрочка/трейд-ин) подтвердить нельзя. В захваченном тексте прямых упоминаний рассрочки или трейд-ина нет. |
| Онлайн-бронирование / личный кабинет покупателя | Частично | Есть кнопка/форма «Забронировать» (имя, телефон, согласия на обработку данных и СМС-рассылку) — это лид-форма для брони через менеджера, не полноценный личный кабинет покупателя. |
| Камеры стройки / ход строительства / дневник | Нет | В собранном контенте не обнаружено; в меню есть пункт «Медиа», содержимое которого не заснято. |
| Архитекторы / архбюро ПО ИМЕНИ | Нет | Используются общие формулировки «Умные планировки», «Дизайнерская отделка», «Удобные дворы» — без имени архитектора или архбюро. |
| Слоган / главный заголовок 1-го экрана | — | Единого слогана на первом экране не обнаружено — это карусель конкретных проектов (например, «ВОСХОД / г. Тюмень / Подробнее», «НОВЫЙ СТАРТ / Продажи квартир финального дома Берша Сити-3»). Ближайшее к позиционированию — заголовок блока «Преимущества наших проектов» с пунктами «Забота о клиентах», «Умные планировки», «Удобные дворы». |

**Вывод по посылу:** АСПЭК продаёт сервис и заботу о клиенте на всех этапах сделки (сопровождение, дизайнерская отделка «под ключ», удобные дворы, развитая инфраструктура) и делает акцент на конкретных проектах и цене/ипотеке, а не на едином слогане. Архитектурное авторство нигде не персонализировано — ни архбюро, ни архитектор по имени не названы. Из-за особенностей SPA часть разделов (Ипотека, Способы покупки, Медиа, страница отдельного проекта) не удалось заснять текстом — статичный сбор не отражает их содержимое.
