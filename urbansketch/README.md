# UrbanSketch MVP — оценка потенциала застройки участка

Веб-инструмент предпроектной оценки земельного участка: контур → пятно застройки →
посадка корпусов → ТЭП, баланс территории, проверка норм и инсоляции → экспорт.

Аналог ядра urbansketch.pro. Сделан как самостоятельное приложение: папку
`urbansketch/` можно целиком вынести в отдельный репозиторий, зависимостей от
остального кода `artel-club` нет.

## Запуск

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # сборка в dist/
npm run smoke     # прогон расчётного ядра в Node без браузера
```

## Что уже работает

**Границы участка**
- импорт кадастрового XML Росреестра (КПТ и выписки, координаты МСК),
- GeoJSON (WGS84 проецируется в локальные метры) и DXF (LWPOLYLINE/POLYLINE),
- ручной ввод координат построчно, с переключателем «первый столбец — X (север)»,
- рисование контура мышью, демонстрационные участки для быстрой пробы.

**Пятно застройки**
- отступ от границ участка и отдельный отступ от красных линий по выбранным сторонам,
- корректное смещение невыпуклых контуров (Clipper), с дырами и разрывами.

**Генерация застройки**
- три стратегии: периметральный квартал, строчная застройка, смешанная (башни + секции),
- дозаполнение свободных мест до норматива плотности и процента застройки,
- соцобъекты (детсад, школа) и паркинг во внутренней части квартала,
- каждый кандидат проверяется на попадание в пятно и на нормативные разрывы,
  поэтому выданный вариант уже проходит проверки; варианты ранжируются по
  продаваемой площади с штрафом за инсоляционный брак.

**Ручная доработка**
- перетаскивание корпусов, поворот (R / ±90°), изменение этажности, дублирование,
- пересчёт всех показателей на лету, отмена/возврат.

**ТЭП и баланс территории**
- площадь участка и застройки, процент застройки, поэтажная и продаваемая площадь,
- плотность (м²/га), средняя этажность, расчётное население,
- потребность в местах ДОУ и школ, машино-местах, озеленении и площадках,
- баланс территории с выявлением дефицита свободной территории.

**Проверки норм**
- размещение в пятне застройки,
- противопожарные разрывы (СП 4.13130, таблица по степеням огнестойкости),
- бытовые разрывы 15/20 м и 10 м «торец — фасад» (СП 42.13330),
- плотность, процент застройки, предельная этажность,
- обеспеченность соцобъектами и парковками.

**Инсоляция (упрощённо)**
- положение солнца на 22 марта по широте участка, шаг 10 минут,
- затенение соседними корпусами, непрерывная продолжительность по каждому фасаду,
- визуализация теней на плане с ползунком времени.

**Экспорт**
- SVG-схема планировочной организации с легендой и масштабной линейкой,
- ТЭП в CSV (Excel, разделитель `;`, BOM),
- GeoJSON посадки для ГИС/САПР,
- сохранение и загрузка проекта в JSON.

## Устройство кода

```
src/geo/         геометрия: площади, смещение полигонов, булевы операции, расстояния
src/domain/      предметная модель:
  norms.ts       нормативные пресеты МНГП и разрывы
  typologies.ts  типовые секции, башни, соцобъекты
  project.ts     проект и расчёт пятна застройки
  tep.ts         ТЭП и баланс территории
  checks.ts      проверки норм
  insolation.ts  солнце, тени, продолжительность инсоляции
  generate.ts    генеративная посадка
src/io/          импорт (XML/GeoJSON/DXF/текст) и экспорт (SVG/CSV/GeoJSON/JSON)
src/ui/          план на SVG и панели интерфейса
src/app/         состояние (useReducer) и сборка экрана
src/dev/smoke.ts прогон ядра без браузера
```

Расчётное ядро не зависит от React и DOM (кроме импортеров, использующих
`DOMParser`) — его можно вынести в серверный сервис или в очередь расчётов
без переписывания.

## Ограничения текущей версии

- Нормативные значения — **редактируемые пресеты**, а не выписка из действующих
  МНГП. Перед выдачей результата заказчику их сверяют с документами города.
- Инсоляция считается упрощённо: 22 марта, окна на 1,5 м, затенение только
  корпусами внутри участка, без окружающей застройки и рельефа. Это отбраковка
  вариантов, а не расчёт по СанПиН 1.2.3685-21.
- Нет квартирографии, инженерных нагрузок, дорожной сети, 3D и многопользовательской
  работы — это следующие шаги.
- Отступ от границ задаётся общим значением плюс отдельный для красных линий;
  индивидуальный отступ по каждой стороне пока не редактируется.
